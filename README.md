# Google Apprenticeship 2027 Prep Partner

Private source backup for Sidhartha's Google Software Application Development Apprenticeship 2027 preparation website.

Live site: https://sidhartha-google-apprenticeship-2027.sidhartha0925.chatgpt.site

## Contents

- Interview-focused 150-question track
- Complete Striver A2Z 442-item track
- Weekly planner and revision workflow
- Per-question notes, mistakes, code, confidence, and bookmarks
- STAR-L behavioral preparation
- Core CS and Smart Quality Test System preparation

## Run locally

The deployable static site is in `dist/`. Open `dist/index.html` in a browser or serve the folder with any static web server.

Progress is stored in each browser's local storage and is not included in this source backup.
